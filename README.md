# Team-task-manager

Project Title: Team Task Manager

Description:
A full-stack web application that allows users to create projects, assign tasks, and track progress with role-based access (Admin/Member).

Tech Stack:
Frontend: React.js
Backend: Node.js, Express.js
Database: MongoDB

Features:
- User Authentication (Signup/Login)
- Role-based Access (Admin/Member)
- Project Creation & Team Management
- Task Assignment & Status Tracking
- Dashboard with Task Overview

API Endpoints:
- POST /api/auth/signup
- POST /api/auth/login
- POST /api/projects
- GET /api/tasks
- PUT /api/tasks/:id

Deployment:
Deployed on Railway

How to Run Locally:
1. Clone repo
2. Run `npm install`
3. Setup .env file
4. Run `npm start`
